    公式与假设

    分数运算先按公式合并，再用分子与分母的最大公约数化简。所有整数用 BigInt 保存，避免大数超过 2^53 后丢失精度。

    公式

    a/b + c/d = (a·d + b·c) / (b·d)

    a/b − c/d = (a·d − b·c) / (b·d)

    a/b × c/d = (a·c) / (b·d)

    a/b ÷ c/d = (a·d) / (b·c)，c ≠ 0

    假设与规则

    • 输入接受 a/b、整数和带分数；带分数的整数部分可带负号，分数部分必须小于 1。
    • 分母不能为 0；除以第二个分数时，它的值不能为 0。
    • 负号统一放在分子，分母始终为正；结果以最简分数显示。
    • 化简使用 gcd(|分子|, 分母)；分子为 0 时结果记作 0/1。
    • 小数显示保留 10 位，第 11 位四舍五入，然后去掉末尾多余的 0。
    • 每个输入整数的位数上限为 40 位，超出会报错，避免页面卡顿。

    常见问题

    结果为什么会自动约分？

    工具用最大公约数把分子分母化成最简形式。约分不改变数值，只是让结果更易读；需要原始分母时可查看计算步骤。

    除以零会怎样？

    会直接报错，因为除以零没有定义。请检查第二个分数的分子是否为零，或改用乘法并说明倒数关系。

    带分数怎么输入？

    把带分数先化成假分数，例如 1 2/3 输入为 5/3。工具输出时会在适当情况下显示带分数形式。
