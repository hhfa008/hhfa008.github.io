公式与假设

转换器先把文本切成词元，再按目标格式重新组合；标点、空格和下划线只作为分隔符，不会出现在驼峰或蛇形结果里。

分词规则

词元 = 按非字母数字、下划线、连字符、空格及驼峰边界切分

驼峰与帕斯卡

驼峰 = 首词小写 + 后续词首字母大写；帕斯卡 = 每个词首字母大写

蛇形与常量

蛇形 = 词元小写用 _ 连接；烤肉串用 -；常量全部大写用 _ 连接

标题与句子

标题 = 首尾词大写、中间短介词小写；句子 = 全文小写后按句首重新大写

假设与规则

  • 缩写（连续大写字母）在驼峰和帕斯卡中整体保留，避免被拆成单个字母。
  • 数字并入相邻词元，例如 v2 update 转为 v2Update，而不是 v2_update。
  • 中文、日文等无大小写的文字和 emoji 原样保留，只对拉丁字母改变大小写。
  • 标题格式使用常见英文小词表（and、of、the、to 等）；首词和末词始终大写。

常见问题

标题格式会把 and、of 这类小词大写吗？

采用常见标题规则，首尾词一律大写，中间的 and、of、the 等短介词和连词保持小写。若你要每个词都大写，可改用“全大写”或逐词处理。

驼峰转换遇到数字和缩写怎么处理？

数字会并入相邻单词，例如 v2 update 转为 v2Update；连续大写缩写会整体保留，避免变成 uR l。建议先检查结果再粘贴到代码里。

转换会改动中文或 emoji 吗？

不会。中文、日文等无大小写概念的文字和 emoji 会原样保留，只处理拉丁字母；分隔符会被统一成当前格式所需的形式。
