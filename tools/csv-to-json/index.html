解析规则
遵循 RFC 4180：双引号字段可以包含分隔符、换行，字段内的双引号写成两个双引号。行尾支持 LF、CRLF 和 CR。

  
类型推断
空字段保持空字符串，true/false 转布尔值，null 转 null，数字转 JSON 数字。超过 15 位有效数字的整数保持字符串。

  
表头处理
空表头按列序命名为 column_1、column_2；重复表头依次加 _2、_3 后缀，并在结果区提示。

  
嵌套与边界
开启嵌套后，a.b.c 会生成三层对象；短行用空字符串补齐，长行的多余单元格忽略。自闭合引号缺失会返回出错行列。




    

  


  

    
常见问题

    
    

          引号里的逗号和换行会处理吗？
          
会。符合 RFC 4180 的双引号字段可以包含逗号、换行和转义的双引号，解析器会把这些内容保留在一个字段里。

        

    

          类型推断会把号码变成数字吗？
          
开启后，纯数字字段会变成 JSON 数字，true/false 变成布尔值。电话号码、邮编、带前导零的编号建议关闭推断，避免丢失格式。

        

    

          表头重复或为空怎么办？
          
重复表头会自动加后缀，空表头会生成 column_1 之类的名字，并在结果中提示。最好先在源文件里整理好表头。
