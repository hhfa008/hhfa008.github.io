统计规则与说明

总字符按 Unicode 码点计，一个 emoji 算一个字符；去空白字符会移除空格、制表符和换行。行按 CRLF、LF 或 CR 拆分，末尾换行会产生一个空行。

拉丁字母和数字按词边界计为一个词；汉字、假名和谚文按字符逐个计。句子按 . ! ? 。 ！ ？ … 切分，段落以空行分隔。

阅读时间把拉丁文按每分钟 200 词、CJK 按每分钟 300 字分别计算后相加，再向上取整到整分钟。这个数字只是估算，实际速度因内容和读者而异。

排序直接比较 Unicode 码点，不使用拼音或系统语言环境，因此在任何设备上结果一致。排序是稳定的：完全相同的行保持原来的先后顺序。

勾选“正则表达式”后，查找串按 JavaScript 正则编译，替换串可以使用 $1、$& 等引用。语法错误会就地显示，不会改动文本。未勾选时查找串按字面量处理。

常见问题

词数和阅读时间是怎么计算的？

拉丁字母和数字按词边界计为一个词；汉字、假名和谚文按字符逐个计。阅读时间按拉丁文每分钟 200 词、CJK 每分钟 300 字分别计算后相加，再向上取整到分钟。

按行排序用的是拼音还是字母顺序？

都不是。排序直接比较 Unicode 码点，不使用系统语言环境，因此同一份文本在不同设备上的顺序一致。排序是稳定的，完全相同的行保持原来的先后顺序。

查找替换支持正则表达式吗？

支持。勾选“正则”后，查找串会作为 JavaScript 正则表达式编译，替换串可以使用 $1、$& 等捕获引用。正则语法错误会在原位置提示，不会执行替换。

文本会被上传或保存吗？

不会。所有统计与转换都在浏览器里完成，页面不发送网络请求，也不读取或写入文本内容。只有语言选择会保存在本机 localStorage。
