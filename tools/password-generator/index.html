    计算方式与假设

    随机数来自浏览器提供的 crypto.getRandomValues，并用拒绝采样消除取模偏差；不使用 Math.random。下面是页面实际使用的公式与规则。

    字符池

    pool = union(selected sets) − ambiguous

    只合并已勾选的字符集；开启“排除易混淆字符”后，从池中删除 0 O o 1 l I | ` ' " 这些字符。

    熵值

    H = length × log₂(pool size)

    单位是 bits。本页按总熵分级：<50 弱，50–79 一般，80–119 强，≥120 很强。分级只反映随机性，不构成安全保证。

    拒绝采样

    limit = ⌊2³² / n⌋ × n; accept if r < limit

    把随机数映射到字符下标时，直接取模会让前几个字符出现概率略高。这里先算可接受区间，落在区间外就重新取值。

    洗牌

    Fisher–Yates: swap(i, random 0…i)

    当“每类至少一个”开启时，先从每个已选字符集各取一个，再用合并后的字符池补足长度，最后整体洗牌，避免固定位置泄露字符类别。

    假设与边界

    • 长度限制为 8–64 位的整数；长度小于已选字符集数量且开启“每类至少一个”时拒绝生成。
    • 字符池大小按去重后的字符数计算；四类字符互不重叠。
    • “每类至少一个”保证每个已选字符集至少出现一次，但不保证每类出现次数相同。
    • 熵值假设每个字符独立均匀抽取；拒绝采样正是为了让这个假设成立。
    • 复制使用系统剪贴板；若浏览器拒绝，文本会被选中供手动复制。

    常见问题

    这个密码生成器安全吗？密码会被上传吗？

    页面不发起任何网络请求，密码只在你的浏览器内存中生成和显示，不会上传、不会写入 localStorage，也没有统计脚本。随机数来自浏览器提供的 crypto.getRandomValues，并通过拒绝采样避免取模偏差。

    熵值多少才算强？

    本页按总熵划分：低于 50 bits 为弱，50–79 bits 为一般，80–119 bits 为强，120 bits 及以上为很强。熵值只描述随机性，不代表某个网站本身安全；仍应为每个站点使用独立密码，并配合密码管理器和两步验证。

    为什么要排除 0 O o 1 l I 这类字符？

    这些字符在手写、打印或某些字体下容易互相混淆，手动输入时可能抄错。排除它们会略微降低字符池和熵值，但能减少输错密码导致的登录失败。

    生成后需要保存密码吗？

    本页不会保存任何生成的密码，刷新或关闭页面后即消失。请把它保存到可信的密码管理器，不要发到聊天工具或写在便签上。每个站点使用不同密码。
