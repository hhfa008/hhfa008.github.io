公式与假设

倒计时开始时先算出结束时刻（performance.now() + 剩余毫秒），之后每一帧只用“结束时刻 − 当前时刻”求剩余值。暂停时把剩余值保存下来，恢复时重新计算结束时刻，所以标签页被节流、电脑休眠再唤醒都不会累积误差。

结束时刻

end = now + remaining

开始或恢复时计算一次；之后不依赖定时器触发的次数。

剩余时间

remaining = max(0, end − now)

剩余时间不会为负；到 0 时停止计时并触发提醒。

显示取整

seconds = ceil(ms / 1000)

显示向上取整到整秒：还剩 0.4 秒时仍显示 00:00:01，到 0 才显示 00:00:00。

  • 小时范围 0–999，分钟和秒范围 0–59，总时长必须大于 0 秒。
  • 提示音由 WebAudio 在本地合成，不使用通知权限，也不上传任何数据。
  • 浏览器在后台可能节流定时器，声音会延迟到页面恢复前台；剩余时间仍按真实时刻计算。
  • 刷新或关闭页面会清空倒计时，不会在后台继续运行。

常见问题

浏览器在后台时会准时响吗？

标签页被节流时提示音可能延迟，恢复前台后会立即显示结束状态。需要严格准点请保持页面在前台，或使用系统闹钟。

结束提示需要通知权限吗？

不需要。工具使用 WebAudio 生成提示音并修改页面标题，不申请通知权限；若浏览器禁止自动播放声音，请先与页面互动一次。

可以设置超过 24 小时吗？

可以按小时输入，但页面展示仍以时:分:秒呈现。超长倒计时请保持页面打开，休眠或关机都会中断。
