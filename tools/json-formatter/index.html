规则与说明

    

      

        
严格 JSON

        
只接受标准 JSON。注释、单引号、尾随逗号、未加引号的键和 NaN 都会被判定为无效；JSON5、JSONC 需要先自行转换。

      

      

        
重复键

        
同一个对象里出现重复键时，后出现的值覆盖先出现的值，最终只保留一个键。摘要按覆盖后的结果计数。

      

      

        
节点与键

        
节点数包含根值、每个对象成员的值和每个数组元素；对象和数组本身也算一个节点。键数是所有对象成员键名的总数，最大深度从根节点 0 开始。

      

      

        
5 MB 上限

        
按 UTF-8 字节计算，超过 5 MB（5,242,880 字节）的内容会被拒绝处理。读取文件时会在读取前检查大小，避免把超大内容塞进页面。

      

    

  


  

    
常见问题

    

      支持注释或尾随逗号吗？
      
不支持。这里使用浏览器原生的严格 JSON 解析，注释、单引号、尾随逗号和未加引号的键都会被判定为无效。JSON5 或 JSONC 需要先自行转换。

    

    

      重复键会怎么处理？
      
解析器遵循 JSON.parse 的行为：同一个对象里出现重复键时，后出现的值覆盖先出现的值，结果只保留一个键。校验摘要也按覆盖后的对象计数。

    

    

      摘要里的节点数和键数是怎么数的？
      
节点数包含根值、每个对象成员的值和每个数组元素；对象和数组本身也算一个节点。键数是所有对象成员键名的总数，最大深度从根节点 0 开始计算。

    

    

      文件会被上传吗？
      
不会。文件读取使用浏览器 FileReader，下载使用本地 Blob 和对象 URL，页面不发送任何网络请求。超过 5 MB 的内容会被拒绝处理。
