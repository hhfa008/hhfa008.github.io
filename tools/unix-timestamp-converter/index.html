ISO 时间 → 时间戳

    公式与假设

    Unix 时间戳是从 1970-01-01T00:00:00Z 起经过的秒数或毫秒数，本身不带时区。页面的所有日期换算都用整数公历算法完成，不依赖系统时区；本地时间只在最后展示时按设备时区格式化。

    单位识别

    |value| ≥ 100,000,000,000 → 毫秒

    10 位数字通常是秒（约 2001–2286 年），13 位是毫秒。边界附近或异常值建议手动指定单位。

    秒 ↔ 毫秒

    ms = seconds × 1000

    反向取整采用向下取整，因此 -1 毫秒按秒显示为 -1 秒，避免跨过 1970 年时出现方向偏差。

    ISO 往返

    epoch = UTC(y,m,d,h,m,s,ms) − offset

    解析支持 Z 或 ±HH:MM；未写时区时按 UTC 解释。格式化始终输出带毫秒的 UTC ISO 字符串。

    • 有效范围与 JavaScript Date 一致：约公元前 271821 年到公元 275760 年（±8.64e15 毫秒）。
    • 负时间戳表示 1970-01-01T00:00:00Z 之前；部分数据库只接受非负值。
    • 本地时间与本地 ISO 的偏移取该时刻设备时区的规则，可能随夏令时变化。
    • 当前时间戳每 0.25 秒刷新一次，仅用于显示，不写入任何存储。

    常见问题

    怎么判断输入是秒还是毫秒？

    工具按位数和合理年份范围自动判断，10 位通常按秒、13 位按毫秒；也可手动切换单位，避免 2038 年附近或极端值误判。

    负时间戳表示什么？

    表示 1970-01-01 00:00:00 UTC 之前的时间。工具支持负值，但部分数据库和接口不接受，存储前请确认范围。

    显示的是本地时间还是 UTC？

    两者都会显示，并明确标注。时区转换由系统规则完成，跨时区沟通时建议以 UTC 为准。
