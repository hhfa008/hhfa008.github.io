公式与假设

输入房租和其他公共费用，再给每位成员一个权重。工具先求权重总和，按比例分配，再用最大余数法补齐到分。

按权重分摊

每人 = 总额 × 本人权重 ÷ 权重总和

最大余数法

先取整到分，剩余的分按小数部分从大到小依次补给成员，保证分项和 = 总额
  • 面积、人数和自定义权重都按同一方式计算，只是权重含义不同。
  • 权重填 0 表示该成员不分摊这一项；所有人的权重都为 0 时无法计算。
  • 金额以最小货币单位（分）计算；余额按最大余数法分配，平手时按成员顺序靠前者优先。
  • 本工具对整张账单只使用一种权重。房租按面积、水电按人数时，请分两次计算后相加。
  • 结果仅为估算，不构成财务建议；实际分摊请以室友之间约定为准。

常见问题

分摊后总额和账单差几分钱怎么办？

工具用最大余数法分配，保证各项分项之和与总额完全一致。多出或少的 1 分会落到权重最高或顺序靠前的人身上，明细里可以看到。

可以一部分按面积、一部分按人数吗？

当前版本对每项费用统一使用一种权重。你可以分两次计算：房租按面积，水电按人数，再把每个人的两项结果相加。

权重填 0 表示什么？

表示该成员不分摊这项费用。所有人权重都为 0 时无法计算，工具会提示至少给一个人正权重。
