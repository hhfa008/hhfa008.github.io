公式与假设

缩放倍数由目标份数除以原份数得到，每条配料的数字乘以同一倍数，单位保持不变。显示格式只影响呈现，不改变实际数值。

缩放倍数

倍数 = 目标份数 ÷ 原份数

配料数量

新数量 = 原数量 × 倍数

假设与规则

  • 原份数和目标份数都必须大于 0；填 0 或负数会直接报错。
  • 分数模式把结果四舍五入到最接近的常用分数（分母 8 或 1/3、2/3），例如 1.5 显示为 1 1/2。
  • 小数模式保留 2 位小数；取整模式四舍五入到整数，正数最小取 1，0 仍为 0。
  • 单位完全不变；需要杯↔毫升或克↔盎司换算时，请先用烹饪单位换算器。

常见问题

缩放后单位会变吗？

不会。工具只改变数字，单位保持你输入的原样。若需要把杯换成毫升，请先做好单位换算再输入。

香料和盐也按比例放大吗？

默认全部按比例缩放，但实际操作中盐、香料和膨松剂常需酌情减少。建议先按比例算，再根据口味微调。

份数可以填 0 吗？

不可以。原份数和目标份数都必须大于 0，否则缩放系数没有意义；工具会提示你修正输入。
