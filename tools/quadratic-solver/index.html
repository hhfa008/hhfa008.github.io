公式与假设

先用判别式 Δ = b² − 4ac 判断根的类型，再代入求根公式。a = 0 时不能使用求根公式，方程退化为 bx + c = 0。

公式

x = (−b ± √(b² − 4ac)) / (2a)，a ≠ 0

Δ > 0：两个不同实根；Δ = 0：一个重根；Δ < 0：一对共轭复根

顶点：(−b / 2a, −Δ / 4a)

两根之和 = −b / a；两根之积 = c / a

a = 0 且 b ≠ 0 时，x = −c / b

假设与规则

  • 系数必须是有限数字，绝对值不超过 10^12；非数字或超范围会报错。
  • 判别式与 0 的差距小于相对误差 10^−12 时按 0 处理，避免浮点误差把重根误判成两个实根。
  • 系数均为整数且 |Δ| ≤ 10^12 时，额外给出化简根号的精确形式；否则只给近似值。
  • 复根写成 re ± im·i；实数范围内没有因式分解形式。
  • 因式形式只适用于 Δ ≥ 0 的二次方程；a = 0 或 Δ < 0 时不显示。
  • 显示保留最多 6 位小数，四舍五入只影响显示，不改变内部计算。

常见问题

判别式为负时根是什么？

没有实根，但有两个共轭复根，实部为 −b/(2a)，虚部为 ±√(−Δ)/(2a)。工具会按复数形式显示。

a=0 时还能用求根公式吗？

不能，因为分母 2a 为零。此时方程退化为 bx+c=0，工具会自动切换到一次方程求解并提示。

结果为分数还是小数？

会同时给出精确形式与近似小数。无理根无法化成有限小数，页面会保留根号表达并注明四舍五入位数。
