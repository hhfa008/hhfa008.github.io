公式与假设

统计量分三步：先解析并排序数据，再计算位置统计量与离散程度，最后按所选口径决定方差分母。所有数值先在浏览器内校验，样本方差要求至少两个数据点。

公式

均值 x̄ = (Σxᵢ) / n

中位数：排序后取中间值；偶数个时取中间两数的平均

众数：出现次数最多的值；所有值只出现一次时没有众数

样本方差 s² = Σ(xᵢ − x̄)² / (n − 1)；总体方差 σ² = Σ(xᵢ − x̄)² / n

标准差 = √方差

四分位：位置 = (n − 1)p，p = 0.25、0.5、0.75，相邻值线性插值

假设与规则

  • 输入按逗号、空格、分号、顿号或换行拆分；空输入会报错，无法解析的记号会指出问题。
  • 允许负数与小数，拒绝 NaN、Infinity 等非有限值；最多 10000 个数。
  • 样本方差与样本标准差至少需要 2 个数据点；单个数据点的总体方差与标准差为 0。
  • 方差用两遍法计算（先求均值，再累加偏差平方），并用补偿求和降低浮点误差。
  • 四分位采用线性插值法（位置 (n − 1)p）；不同教材定义略有差异，报告时应注明方法。
  • 显示保留最多 6 位小数，四舍五入仅影响显示，不改变内部计算值。

常见问题

样本标准差和总体标准差差在哪？

样本方差除以 n−1，总体方差除以 n。样本用于推断更大的总体，除数更大会让结果略高；若数据就是全部总体，请选总体。

有多个众数怎么办？

会全部列出，并提示数据是多峰的。如果每个数都只出现一次，则没有众数，工具会明确说明而不是随便选一个。

中位数和四分位怎么算？

先排序，中位数取中间值或中间两数的平均。四分位采用常见插值法，不同教材定义可能略有差异，报告时应注明方法。
