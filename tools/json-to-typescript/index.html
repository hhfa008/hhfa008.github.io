类型推断
字符串、数字、布尔值、null 分别推断为 string、number、boolean、null；对象按字段递归推断，空数组推断为 unknown[]。

  
数组合并
数组会合并所有元素的结构：仅部分元素拥有的键标为可选（?），类型冲突时生成联合类型，出现 null 时保留可空（| null）。

  
命名规则
根类型名转换为 PascalCase；嵌套对象用“父类型名 + 字段名”命名，数组成员用“父类型名 + 字段名 + Item”，重名时追加数字后缀。

  
限制
不推断字面量类型、日期格式或品牌类型；空对象输出 Record<string, unknown>。生成的代码是起点，请按业务补精确类型。




    

  


  

    
常见问题

    
    

          数组里不同类型会怎么处理？
          
工具会合并所有元素的结构：共同字段保留，缺失字段标记为可选，类型冲突时生成联合类型。若差异过大，建议手动拆分模型。

        

    

          可选和可空是一回事吗？
          
不是。可选是字段可能不存在（?），可空是字段存在但值为 null。工具会分别推断，避免把 null 误当成缺失。

        

    

          生成的类型能直接用吗？
          
可作为起点。请按业务补充更精确的字面量类型、日期字符串格式和品牌类型，并检查根类型命名是否与项目约定一致。
