公式与假设

渲染分两步：先把整段输入中的 & < > " ' 全部转义，避免被浏览器当作标签；再按块级和行内规则生成固定的白名单标签。因此原始 HTML 只会显示为文字，不会执行。

安全模型

escape(input) → whitelisted block/inline tags → escaped attributes
  • 块级支持：1–6 级标题（# 加空格）、围栏代码块（三个反引号）、引用（>）、无序列表（- * +）、有序列表（1.）、水平线（三个以上 - * _）。
  • 行内支持：**粗体**、__粗体__、*斜体*、_斜体_、`行内代码`、[文字](链接)。代码内容先占位，不再参与粗斜体解析。
  • 链接仅允许 http、https、mailto 和相对地址；javascript:、data:、vbscript: 等协议会被拒绝，只保留链接文字。带实体的伪装协议同样会被拒绝。
  • 列表按缩进嵌套（建议两个空格）；空行会结束当前列表。段落内的单个换行显示为 <br>。不支持的语法按普通文字显示。
  • 不支持表格、任务列表、脚注、图片和原始 HTML；未闭合的代码块会一直延续到文本末尾。输入上限 200,000 字符，所有处理都在本地完成。

常见问题

这里的 HTML 为什么安全？

渲染前会先转义原始 HTML 标签，只生成受控的标签，避免脚本注入。即便如此，导出的 HTML 放到你自己的站点前仍应复查。

支持表格和任务列表吗？

当前只覆盖安全子集，表格、任务列表和脚注暂不支持。遇到未支持语法会按普通文本显示，不会报错。

导出的 HTML 可以直接发布吗？

可以用于简单页面，但不含完整样式和站点结构。发布前请补上标题层级、语言属性和必要的可访问性标记。
