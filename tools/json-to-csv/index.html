公式与假设

    

      
      


  
列与展平
默认展平嵌套结构：user.name 用点号连接，数组用索引连接。所有行取键的并集，只有在部分行出现的键会被补空。

  
转义规则
单元格包含分隔符、双引号、换行或首尾空白时用双引号包裹，内部双引号写成两个双引号。行以 CRLF 分隔。

  
BOM 与空值
UTF-8 BOM 可选，主要用于让 Excel 正确识别中文。null 和缺失键输出为空单元格；空数组和空对象在展平时写成 [] 和 {}。

  
边界
根节点必须是数组；空数组输出空内容。关闭展平后，嵌套值会以紧凑 JSON 文本放进同一个单元格。非法 JSON 会返回出错行列。




    

  


  

    
常见问题

    
    

          嵌套对象会变成什么？
          
开启展平后，user.name 会变成一列，列名用点号连接。数组默认也展平为带索引的列；若结构过深，建议先裁剪数据。

        

    

          为什么 Excel 打开中文乱码？
          
Excel 在部分系统上默认按本地编码读取 CSV。开启 BOM 后通常能正确识别 UTF-8，再导入就不会乱码。

        

    

          空数组或非数组会怎样？
          
空数组会生成只有表头或完全空的文件；传入对象而不是数组会报错，提示你检查根结构。
