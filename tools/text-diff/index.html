公式与假设

差异按行计算：先找两段文本的最长公共子序列（LCS），再回溯得到未变、删除和新增行。替换会被表示为一段删除加一段新增，不做行内字符级高亮。

比较规则

LCS(linesA, linesB) → same / del / add · O(n×m)
  • 比较复杂度约为 O(n×m)。为保护页面，单边上限 2,000 行，且行数乘积上限 4,000,000；超过时提示分段处理。
  • “忽略空白”会先去掉行首行尾空白并把连续空白折叠成一个空格；“忽略大小写”再统一转小写。显示仍使用原始文本。
  • CRLF 和单独的 CR 会统一成 LF。末尾换行会多出一个空行，因此“a\n”和“a”会被视为不同。
  • 并排视图把相邻的删除与新增行按顺序对齐；数量不等时较短一侧留空，便于看出替换关系。
  • 所有比较都在本地完成，不上传文本；工具只处理纯文本，不解析 Word、PDF 或二进制内容。

常见问题

为什么缩进变化也被标成差异？

默认严格比较每个字符，缩进变化会算作修改。开启“忽略空白”后会先统一空格和行尾，再比较内容。

大文本会不会很慢？

工具使用按行 LCS 算法，几千行通常很快；超长文本会触发性能上限并提示你先分段比较，避免页面卡死。

能对比 Word 或 PDF 吗？

不能直接读取二进制文档。请先复制粘贴纯文本，或另存为 txt 后再对比；格式、图片和批注不会参与比较。
