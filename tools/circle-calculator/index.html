公式与假设

输入半径、直径、周长或面积中的任意一项，本工具会先换算成半径，再求出其余三项；扇形使用同一个半径。

整圆关系

d = 2r；C = 2πr；A = πr²

由其余量反推半径

r = d/2 = C/(2π) = √(A/π)

扇形与弧长

扇形面积 = πr² × θ/360；弧长 = 2πr × θ/360

假设与规则

  • 所有圆的量都必须大于 0；输入 0 或负数会被拒绝。
  • 圆周率使用双精度 π，结果最多保留 4 位小数并四舍五入。
  • 圆心角以度为单位，必须大于 0 且不超过 360；留空时不计算扇形。
  • 扇形和弧长使用上一步求出的半径；切换输入类型后会重新计算。

周长与弧长的单位是长度，面积的单位是长度平方。

常见问题

半径 5 的圆周长和面积是多少？

周长约为 31.42，面积约为 78.54。公式分别是 2πr 和 πr²，结果按你设置的精度四舍五入。

输入直径时会把半径算错吗？

不会。工具根据你选择的输入类型分别处理，直径先除以 2 再进入其他公式；请确认选中了正确的输入项。

扇形计算需要什么角度？

需要圆心角，单位为度。扇形面积 = πr² × θ/360，弧长 = 2πr × θ/360，角度超过 360° 会被拒绝。
