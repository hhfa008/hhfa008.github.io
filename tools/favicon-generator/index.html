公式与假设

图标由 canvas 现场绘制：先按尺寸和圆角画底色（或留透明），再按字符数量计算字号，把文字或 emoji 居中绘制，最后用 toBlob 导出 PNG。整个过程不读取网络，也不上传任何数据。

尺寸与字号

圆角半径 = 尺寸 × 百分比 / 100
单字符字号 ≈ 尺寸 × 0.58
多字符字号按字符数缩小，下限为尺寸 × 0.18

假设与规则

  • 固定生成 16、32、180、192、512 五种尺寸；自定义尺寸会被夹到 16–512。
  • 文字按 Unicode 字素截断到 4 个字符，emoji 按一个字符计算。
  • 圆角范围 0–50%，50% 在正方形上就是圆形；透明背景时只导出文字与透明像素。
  • emoji 由系统字体渲染，不同设备的字形可能不同；下载文件命名遵循 favicon 与 PWA 的常见约定。

常见问题

这些文件分别放在哪里？

16 和 32 用于浏览器标签页，180 用于 iOS 主屏，192 和 512 用于 PWA 与 Android。放在站点根目录并在 HTML 里用 link 标签引用。

用 emoji 做图标有什么风险？

不同系统的 emoji 字形不同，可能与你预览的效果有差异，而且部分旧设备渲染不一致。正式品牌图标建议用简洁字母或 SVG。

圆角和背景色会影响小尺寸吗？

会。16px 下细节几乎不可见，圆角过大会让字母显得太小。生成后请在小尺寸下实际查看，必要时减少文字或提高对比度。以上处理全部在本地完成，不上传。
