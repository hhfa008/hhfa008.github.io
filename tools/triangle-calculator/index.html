公式与假设

本工具根据已知条件，用余弦定理与海伦公式求出三角形的全部边长、角度与面积。

海伦公式（SSS）

s = (a + b + c) / 2；面积 = √(s(s−a)(s−b)(s−c))

余弦定理（求角）

A = arccos((b² + c² − a²) / (2bc))

两边夹角（SAS）

a = √(b² + c² − 2bc·cos A)；面积 = ½·b·c·sin A

假设与规则

  • 输入边长必须大于 0；SSS 还需满足 a + b > c、a + c > b、b + c > a。
  • 两边之和恰好等于第三边时视为退化，直接报错。
  • SAS 的夹角必须是两条已知边之间的角；给对角无法唯一确定三角形。
  • 角度默认以度显示；选择弧度时，输入与输出都按弧度处理。
  • 结果按页面显示的 4 位小数四舍五入，计算过程使用双精度浮点数。

三角之和恒为 180°（或 π 弧度）。

常见问题

3-4-5 是什么样的三角形？

直角三角形，面积 6，周长 12，三个角约为 36.87°、53.13° 和 90°。满足 3² + 4² = 5²。

为什么任意三边不一定能组成三角形？

必须满足任意两边之和大于第三边。若等于第三边则三点共线，面积为零；小于则图形不存在，工具会报错。

SAS 输入时夹角是哪一条？

夹角必须是两条已知边之间的角。若给的是对角，不能唯一确定三角形，需要改用其他已知条件。
