公式与假设

配色全部由 HSL 推导：保留基色的饱和度与明度，只在色相环上做加减，得到互补、类似、三角、四角与单色五种组合。明暗梯度则固定色相与饱和度，把明度在 6% 到 94% 之间等距铺开。

公式

H' = (H + Δ) mod 360
L' = clamp(L + ΔL, 6, 94)
gradient L(i) = 94 − 88 × i / (n − 1)

假设与规则

  • 色相采用 0–360° 圆周，超出范围自动取模；饱和度与明度取 0–100%。
  • 每种和谐模式固定输出 5 个颜色，方便直接排成一组色板。
  • RGB / HSL 转换按整数通道四舍五入，HEX 统一输出为小写 6 位，可能产生 ±1 的显示差异。
  • CSS 变量按 --前缀-1 到 --前缀-n 生成；前缀只允许字母开头，可含数字和连字符。
  • 工具不检查 WCAG 对比度，也不保证文字与背景的可读性，请在设计稿里再用对比度工具验证。

常见问题

互补色和类似色有什么区别？

互补色在色相环上相差约 180°，对比强、适合强调；类似色相差约 30°，整体更协调。工具按 HSL 色相计算，饱和度和明度会尽量保持。

导出的 CSS 变量能直接用吗？

可以，格式是 --color-1 到 --color-n，放进 :root 后即可用 var() 引用。请根据项目命名规范重命名，并检查深色模式下的可读性。

为什么浅色和深色梯度有时不够均匀？

梯度按明度线性调整，但人眼对明度的感知不是线性的，某些色相在中段会显得跳。可以手动微调色标位置。以上处理全部在本地完成，不上传。
