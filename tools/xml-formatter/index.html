校验范围
只检查标签是否闭合、嵌套是否交叉、注释与 CDATA 是否完整，不校验 XSD、DTD 或业务字段。标签名区分大小写。

  
格式化规则
每个标签独占一行并按层级缩进；纯文本元素保持同一行，属性原样保留，自闭合标签保留 /> 写法。

  
CDATA 与注释
CDATA 内容不做改写，注释内容不变。压缩模式默认保留注释，可关闭；两种模式都保留 CDATA。

  
压缩与错误
压缩会去掉标签之间的缩进空白，文本内容保持原样。标签不配对时返回第一个异常的行列，便于定位漏写或多余的闭合标签。




    

  


  

    
常见问题

    
    

          会验证 XML Schema 吗？
          
不会。工具只检查标签嵌套和基本语法，不校验 XSD、DTD 或业务字段。结构合法的 XML 仍可能不符合你的接口约定。

        

    

          CDATA 和注释会被改动吗？
          
默认保留原内容。格式化只调整标签之间的缩进，不会改写 CDATA 里的文本或注释内容；压缩模式会保留它们但去掉多余空白。

        

    

          为什么有些自闭合标签被展开？
          
工具统一按你选择的风格输出，自闭合标签可保留为 />。若原文件混用两种写法，格式化后会被归一，这是预期行为。
