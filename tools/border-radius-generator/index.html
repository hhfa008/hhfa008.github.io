公式与假设

border-radius 的顺序固定为左上、右上、右下、左下，并允许 CSS 的省略规则：四值相同时写一个值，两组对角相同写两个值，仅左下与右上相同时写三个值。斜杠语法把水平半径和垂直半径分开，让每个角变成椭圆。

语法

border-radius: TL TR BR BL;
border-radius: 水平 / 垂直;

假设与规则

  • 支持 px 与 % 两种单位，可写小数；负数、其他单位和空值都会报错。
  • 百分比相对元素自身的宽度（水平）和高度（垂直），元素尺寸变化时圆角会跟着变形。
  • 工具按 CSS 规则自动压缩重复值，但展开后的四角输入始终保留，不会丢失。
  • 浏览器会把相邻角的半径和限制在边长以内，因此超大数值看起来可能比输入小。

常见问题

斜杠语法是什么？

border-radius: 水平半径 / 垂直半径，可以让每个角成为椭圆。例如 50% / 25% 会产生横向更扁的圆角。

为什么四个值相同时只显示一个？

CSS 允许省略重复值，一个值表示四角相同。工具会自动压缩输出，但你的输入不会丢，展开后仍能看到四角。

百分比和像素可以混用吗？

可以，但含义不同：百分比相对元素宽高，像素是固定长度。尺寸变化时百分比圆角会跟着变形，需要稳定外观时优先用像素。以上处理全部在本地完成，不上传。
