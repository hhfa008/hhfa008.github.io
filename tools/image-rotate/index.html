公式与假设

图片在浏览器里解码到 canvas，按旋转角度重新设置画布宽高，再用 canvas.toBlob 编码下载。旋转只按 90° 步进，不裁剪画面；翻转作为独立状态叠加，重置后恢复初始方向。

旋转后的尺寸

90° / 270°：newW = srcH，newH = srcW；0° / 180°：尺寸不变

画布按旋转后的外接矩形创建，所以竖图转横图不会被裁掉。

翻转

水平：x → srcW − x；垂直：y → srcH − y

先翻转再旋转。两者可叠加，按钮可随时再次点击取消。

  • 旋转和翻转不改变像素数量，但 JPG 重新编码会有轻微损失；需要无损请选 PNG 输出。
  • 输出 JPG 时透明区域会填白；PNG 与 WebP 可保留透明。
  • 带 EXIF 方向的照片由浏览器解码时自动摆正，再应用本工具的旋转。
  • 所有操作只影响当前预览；原始文件不会被修改，下载文件名带方向后缀。
  • 像素超过 4000 万或文件超过 30MB 的图片会被拒绝；关闭页面后结果不会保留。

常见问题

旋转 90° 后尺寸会变吗？

会。90° 和 270° 会交换宽高，180° 保持宽高不变。工具会按旋转后的实际尺寸输出画布，避免图片被裁掉。

翻转和旋转可以叠加吗？

可以。翻转会记录为独立状态，再旋转时按当前方向应用。连续操作后若想重来，重置按钮会恢复初始方向。

会损失画质吗？

旋转和翻转本身不改变像素内容，但重新编码为 JPG 会带来轻微损失。需要无损时可选择 PNG 输出，体积会更大。以上处理全部在本地完成，不上传。
