公式与假设

图片在浏览器里解码到 canvas，按最大宽高缩放后用 canvas.toBlob 重新编码，整个过程没有任何网络请求。显示的前后体积是文件字节数，压缩率按原图字节数计算。

缩放比例

scale = min(1, maxW / w, maxH / h)

任一方向填 0 表示该方向不限制；结果取整到整数像素，最小 1px。

压缩率

saved% = (before − after) / before × 100

保留 1 位小数，四舍五入；结果为负表示体积变大。

  • 质量参数只影响 JPG 与 WebP；PNG 为重新编码，体积可能变大，透明图请保留 PNG。
  • 输出格式选“保持原格式”时沿用源文件的 JPG / PNG / WebP 类型；浏览器不支持编码 WebP 时会就地报错。
  • 透明像素输出成 JPG 时会填白底；带 EXIF 方向的照片由浏览器解码时自动摆正。
  • 文件大小、尺寸等统计信息只用于本次会话，关闭页面即丢失；工具不写入本地存储。
  • 像素超过 4000 万或文件超过 30MB 的图片会被拒绝，避免浏览器卡死。

常见问题

压缩会改变图片尺寸吗？

只有超过你设置的最大宽高时才会等比缩小，否则保持原尺寸，仅调整编码质量。缩小和降质都会让体积下降，但画质损失来源不同。

PNG 压缩后为什么反而更大？

浏览器把 PNG 重新编码为有损或不同色深时，体积不一定下降。需要明显缩小体积可改用 WebP 或有损 JPG，透明图请保留 PNG。

图片会被上传到服务器吗？

不会。读取、缩放和编码都在浏览器本地完成，页面没有网络请求。关闭页面后，未下载的结果不会保留。以上处理全部在本地完成，不上传。
