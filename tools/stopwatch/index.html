公式与假设

秒表不靠逐帧累加，而是记录开始时刻与暂停时已经累计的时间；显示值 = 暂停累计 + (当前时刻 − 最近一次开始时刻)。因此切换标签页、窗口被挂起再恢复，都会按真实经过时间继续。

已用时间

elapsed = pausedTotal + (now − start)

now 与 start 都来自单调时钟 performance.now()，不受系统时间调整影响。

分圈时间

split(k) = total(k) − total(k − 1)

每次计次记录当时的累计时间，与上一次记录的差就是这一圈用时。

显示精度

HH:MM:SS.mmm

显示向下取整到毫秒；小时不封顶，超过 99 小时会显示三位小时。

  • 暂停期间不累计时间；多次暂停会逐次累加已用时间。
  • 计次按累计时间递增记录；重置会同时清空总时间和全部计次。
  • 刷新或关闭页面后计时状态不保留，需要长期记录请先复制结果。
  • 页面隐藏时界面可能不刷新，但恢复后会按时间戳差值立即补齐，不会漂移。

常见问题

切换标签页后计时会停吗？

不会。计时基于时间戳差值而不是逐帧累加，即使页面被挂起，恢复后仍会按真实经过时间更新。

计次和总时间是什么关系？

每次计次记录的是当前总时间，与上一次的差值就是这一圈用时。重置会同时清空总时间和所有计次。

页面关闭后还能恢复吗？

不能。计时状态只保存在当前页面内存中，刷新或关闭会清空；需要长期记录请手动抄下结果。
