公式与假设

内容先映射到 Code 128B 的字符值（ASCII 码减 32），加上起始符后按规则计算校验位，再拼上停止符，最后把每个符号展开成黑白模块。预览、SVG 与 PNG 全部在本地生成，页面没有任何网络请求。

校验位

checksum = (104 + Σ value_i × i) mod 103

起始符 B 的值为 104，数据字符从第 1 位开始乘；余数 0–102 就是校验位。

模块总数

modules = 11 × (字符数 + 2) + 13

起始符、数据、校验位各 11 个模块，停止符 13 个模块；静区另加 10 个模块。

  • 仅支持 Code 128B 子集：ASCII 32（空格）到 126（~）。中文、全角符号和控制字符会就地报错并指出位置。
  • 校验位由工具自动计算，不需要手动输入；统计区会显示实际使用的校验值。
  • 静区固定为左右各 10 个模块。打印或印刷时不要把条码裁到边缘，也不要横向拉伸。
  • PNG 的条宽由“模块宽度”决定，高度固定为适合预览的比例；SVG 为矢量，缩放后仍清晰。
  • 内容最多 80 个字符，避免生成过宽的图形；所有结果只存在于当前页面。

常见问题

Code 128B 支持中文吗？

不支持。Code 128B 只覆盖 ASCII 字符集，中文需要其他条码类型或先编码。请用字母、数字和常见半角符号。

校验位需要自己加吗？

不需要。工具会按 Code 128 规则自动计算并追加校验位，你只输入原始内容；输出里会标明校验位值。

打印时要注意什么？

保持足够静区、不要拉伸条码比例，并按打印机分辨率输出足够尺寸。条宽过窄会导致扫码失败，建议先用目标设备实测。以上处理全部在本地完成，不上传。
