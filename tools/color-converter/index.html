公式与假设

HEX 与 RGB

3 位 HEX 每位重复一次展开为 6 位（#b93 → #bb9933）。RGB 每个通道 0–255，与 HEX 一一对应。

HSL 与 HSV

色相 H 取 0–360°（超出后环绕），饱和度 S 取 0–100%。HSL 的 L 是亮度，HSV 的 V 是明度，两者公式不同但可互相换算。

CMYK

CMYK 由 RGB 近似换算：K = 1 − max(R,G,B)。屏幕 RGB 与印刷 CMYK 缺少 ICC 配置时并非一一对应，结果仅供沟通参考。

WCAG 对比度

先对每个通道做 sRGB 线性化，再按 0.2126R + 0.7152G + 0.0722B 求相对亮度。对比度 = (L1 + 0.05) / (L2 + 0.05)，保留两位小数。

常见问题

CMYK 转换准确吗？

屏幕上的 RGB 与印刷 CMYK 不是一一对应，缺少 ICC 色彩配置时会因纸张、油墨和印刷机不同而变化。结果适合沟通参考，不等于印厂最终值。

对比度 4.5:1 是什么标准？

WCAG AA 对正文的要求是至少 4.5:1，大号文字可放宽到 3:1；AAA 对正文要求 7:1。工具会按你选择的两个颜色计算并标注等级。

3 位 HEX 怎么展开？

#b93 等价于 #bb9933，每位重复一次。工具会自动展开后再转换，避免把短写法误读成其他颜色。
