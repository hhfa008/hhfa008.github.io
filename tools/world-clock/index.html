    公式与假设

    所有当地日期时间都由 Intl.DateTimeFormat 按 IANA 时区名称计算，包括历史上的夏令时规则；页面不手算偏移，也不访问网络。时差 = 目标时区偏移 − 本地时区偏移，随当天是否处于夏令时自动变化。

    时区偏移

    offset = wallTime(zone) − UTC

    通过把当地墙上时间与同一时刻的 UTC 对齐得到偏移分钟数，因此能反映夏令时。

    相对本地时差

    diff = offset(target) − offset(local)

    显示为“比本地快/慢多少”；同一时刻两边日期不同的会额外标注昨天或明天。

    昼夜标记

    06:00 ≤ hour < 18:00 → 白天

    只是粗略分段，不包含季节、纬度或真实日出日落时间。

    • 时区数据来自浏览器内置的 IANA 数据库，旧浏览器可能缺少较新的时区名称。
    • “本地时区”取自设备当前的系统设置；更改系统时区后刷新页面即可更新。
    • 城市列表只包含时区代表城市，同一时区的其他城市结果相同。
    • 页面不保存敏感数据；仅把添加的时区列表写入浏览器本地存储，可随时删除。

    常见问题

    时差会随夏令时变化吗？

    会。工具使用 Intl 的时区数据，自动遵循各地区的夏令时规则。跨季节比较时，请以当天显示的时差为准。

    为什么某个城市找不到？

    列表依赖浏览器支持的 IANA 时区名称，旧浏览器可能缺少新时区。可改选同一时区的代表城市，或升级浏览器。

    昼夜标记按日出日落算吗？

    不是。这里只用当地小时大致区分白天和夜晚，不包含季节、纬度和真实日出日落时间，仅供快速参考。
