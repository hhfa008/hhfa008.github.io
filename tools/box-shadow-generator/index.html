公式与假设

每层阴影最终拼成一段 CSS：可选的 inset 关键字，加上水平偏移、垂直偏移、模糊半径、扩散半径和 rgba() 颜色。多层之间用逗号连接，顺序就是绘制顺序。

公式

inset? Xpx Ypx Blurpx Spreadpx rgba(R,G,B,A)
box-shadow: layer1, layer2, …

假设与规则

  • X、Y、扩散可以为负数；模糊半径必须大于或等于 0，否则报错。
  • 透明度范围是 0–1，输出最多 2 位小数；颜色与透明度会合成 rgba()。
  • 长度值保留最多 2 位小数并去掉多余的 0；单位统一输出 px。
  • 每次生成 1–8 层；列表靠前的阴影绘制在上层，可能遮住后面的层。

常见问题

多层阴影的顺序有影响吗？

有。CSS 中先写的阴影绘制在上层，后写的在下层。工具按列表顺序输出，可拖动调整，避免被上层遮住。

为什么 inset 阴影看不见？

inset 阴影画在元素内部，若元素没有背景或背景透明，可能只看到边缘。另外扩散和偏移过大时会超出元素范围。

颜色带透明度可以直接用 rgba 吗？

可以。工具把颜色和透明度合成 rgba()，也接受带 alpha 的输入。复制到 CSS 后请确认与你的主题色变量兼容。以上处理全部在本地完成，不上传。
