安装步骤

  1. 解压下载的 ZIP，得到 ClipSync.app。
  2. 拖到「应用程序」（/Applications）。
  3. 移除隔离属性（未公证的 ad-hoc 签名应用需要这一步）：
xattr -dr com.apple.quarantine /Applications/ClipSync.app
  1. 右键点按（Control-单击）ClipSync 图标 → 打开。首次启动若仍被拦截，再到「系统设置 → 隐私与安全性」里点「仍要打开」。
  2. 两台 Mac 上都填入相同的 Shared key，即可开始同步剪贴板。
安装说明：ClipSync 使用 ad-hoc 签名，未经过 Apple 公证，因此首次打开会出现安全提示。本页提供的 SHA-256 可用于校验下载文件完整性。应用仅支持 arm64（Apple Silicon），系统要求 macOS 13 或更高。

使用前须知

  • 两机同一 Shared key：参与同步的每台 Mac 必须配置完全相同的 Shared key，否则无法互相识别。
  • 仅 arm64：Intel Mac 无法运行此版本。
  • 未公证：这是个人分发构建，不是 Mac App Store 应用；如上所述用 xattr 与右键打开放行。
  • 来源校验：安装前可核对 SHA-256：shasum -a 256 ClipSync.app.zip。
