## 更新版本

1. 用新构建替换 `ClipSync.app.zip`。
2. 同步更新 `index.html` 中的版本号与 SHA-256。
3. 提交并推送；如启用静态托管则重新部署。

## 本地预览

直接用浏览器打开 `index.html`，或在目录内运行 `python3 -m http.server`。
