Weaviate — what it is actually for

Weaviate is an open-source vector database with hybrid search, embedding modules, and a managed cloud. Teams can self-host the open-source edition or use Weaviate Cloud with a free cluster.

Short answer: use Weaviate when you need self-hosted vector search. It is a open source + free cloud tier + usage-based cloud service from Weaviate; the official pricing source is linked below.

What Weaviate is used for

  • Self-hosted vector search
  • Hybrid keyword and vector retrieval
  • RAG applications with embedding modules

Source: official product page and official documentation.

Who Weaviate is for

  • Teams that want an open-source or self-hosted vector database
  • Hybrid search workloads
  • Kubernetes-based deployments

Source: official documentation.

Who it is not for

  • Teams that want fully managed operations with no infrastructure work
  • Buyers who need the largest managed vector ecosystem

Source: documented plans, limits, and deployment model on the official product page.

Pricing

  • Weaviate Cloud includes one always-free cluster per user.Source: weaviate.io
  • Paid cloud starts at US$45/month with pay-as-you-go scaling and usage-based embedding and query-agent features.Source: weaviate.io
  • The open-source database can be self-hosted at no license cost.Source: weaviate.io

Weaviate FAQ

Is Weaviate free?

Yes. The open-source database can be self-hosted for free, and Weaviate Cloud includes one free cluster per user.

Does Weaviate support hybrid search?

Yes. Weaviate documents hybrid search that combines vector and keyword retrieval.

What does Weaviate Cloud cost?

Paid cloud starts at US$45/month with usage-based scaling. The official pricing page lists current rates.
