Cohere Embed — what it is actually for

Cohere's Embed 5 family provides Pro embeddings for indexing and Fast embeddings for queries in a shared embedding space. Pricing is per input token, with a free trial key for evaluation.

Short answer: use Cohere Embed when you need enterprise search and rag indexing. It is a usage-based api service from Cohere; the official pricing source is linked below.

Pricing

  • Embed 5 Pro text embeddings are listed at US$0.12 per 1M tokens; Embed 5 Fast at US$0.08 per 1M tokens.Source: cohere.com
  • Image embeddings are listed at US$0.40 per 1M tokens. Embeddings are billed on input tokens only.Source: cohere.com
  • A trial API key allows 1,000 calls per month. Model Vault dedicated instances start at US$2,000/month.Source: cohere.com

Pro and Fast share an embedding space, so a common pattern is to index with Pro and query with Fast.

Cohere Embed FAQ

Is Cohere Embed free?

A trial API key allows limited use for evaluation. Production use is billed per token.

What is the difference between Embed 5 Pro and Fast?

Pro is positioned for indexing and quality-critical retrieval, while Fast is positioned for queries and high-volume traffic. Pro costs US$0.12 and Fast US$0.08 per 1M text tokens.

Do Pro and Fast embeddings work together?

Yes. Cohere states that the two models share an embedding space, so you can index with Pro and query with Fast.
