Comparison FAQ

Which AI services in this directory have a free tier?

Free tiers, free credits, free trials, or free open-source editions are published by ChatGPT, Claude, Gemini, DeepSeek, Mistral Le Chat, GitHub Copilot, Cursor, OpenAI Codex, Stability AI, Adobe Firefly, Runway, Pika, Luma, Kling AI, ElevenLabs, Deepgram, AssemblyAI, Azure AI Speech, Voyage AI, Pinecone, Weaviate, OpenAI Agents SDK, LangGraph, CrewAI, Dify, n8n, LangSmith, Braintrust, Arize Phoenix, W&B Weave, and Ragas. The table marks each service's free option.

Which AI coding tools use a subscription?

GitHub Copilot, Cursor, Claude Code, OpenAI Codex, and JetBrains Air are sold through subscriptions, plan-based access, or credits rather than a single per-token price.

Which services bill by usage?

Usage-based billing appears in API products and includes OpenAI API models, DeepSeek, Mistral, Stability AI, FLUX, Google Veo, OpenAI Audio, Deepgram, AssemblyAI, Azure AI Speech, OpenAI Embeddings, Cohere Embed, Voyage AI, Pinecone, Weaviate Cloud, and LangSmith, among others.

Are the prices in this directory current?

The directory was checked on 2026-10-25. Prices change frequently, so each row links to the provider's official pricing page instead of copying every regional price.
