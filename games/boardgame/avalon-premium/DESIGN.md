# Avalon 阿瓦隆 · 精品版设计

## 1. 定位

Avalon 是一款把「隐藏身份、组队投票、任务破坏、终局暗杀」压缩进 20–30 分钟的身份推理桌游。精品版只做官方 5 人基础局：梅林、派西维尔、忠臣对抗莫甘娜与刺客。五个任务人数为 2 / 3 / 2 / 3 / 3；5 人局每个任务只需要 1 张失败卡，任务 4 需两张失败的规则只属于 7 人以上游戏。正义方赢下三次任务后，刺客还有一次暗杀梅林的机会。

精品版的目标不是增加规则，而是把四个关键瞬间做清楚：

1. **我看到了什么**：身份卡只展示本人角色与规则允许的知识。
2. **我该不该同意这支队伍**：队伍名单、连续否决、历史投票一屏可见。
3. **任务卡到底几张失败**：只公开失败数量，不公开来源。
4. **刺客该刀谁**：把公开投票历史整理成可读的复盘面板。

## 2. 规则实现

- 角色：`merlin` / `percival` / `loyal` / `morgana` / `assassin`，固定 3 好 2 坏。
- 任务：`QUEST_SIZES = [2,3,2,3,3]`，`FAILS_TO_FAIL = [1,1,1,1,1]`，胜利线 3，连续否决上限 5。
- 流程：`propose → vote → mission → (next quest | assassin | over)`。
- 投票：5 人全体投票，严格多数（3 票）通过；平票视为否决；通过后否决计数清零。
- 任务：队伍成员秘密提交成功/失败；好人不能失败；5 人局 1 张失败即任务失败。
- 结局：邪恶 3 次破坏立刻获胜；正义 3 次成功进入暗杀；刺客命中梅林邪恶翻盘，否则正义获胜；连续 5 次否决邪恶获胜。
- 隐藏信息：`publicView(state, viewer)` 返回本人角色 + 每席 `roleKnowledge` token；梅林见 `evil`，派西维尔见 `magic`（梅林/莫甘娜不可区分），邪恶见 `evil-ally`，忠臣全 `unknown`。投票过程中只暴露“是否已投”，结算后公开票面；任务卡永远只公开数量。
- 引擎是 UMD 纯函数模块，不依赖 DOM；角色发牌复用 `games/shared/shuffle.js` 的 seeded Fisher-Yates；AI 随机性保存在可序列化的 `rngState`，因此服务端克隆、重放和联机同步都不会漂移。`state` 可完整 `JSON.stringify`。

## 3. AI

AI 按阶段拆成四个纯决策函数：

- `aiProposeTeam`：梅林避开已知邪恶；派西维尔优先选一位魔法师；邪恶优先带同伙；忠臣按随机偏好组队。
- `aiVote`：邪恶在队伍含同伙时高概率赞成，干净队伍在否决接近 5 次时倾向反对；梅林对含邪恶队伍强烈反对；派西维尔避免同时放进两位魔法师；忠臣会避开曾在失败任务中出现的座位。
- `aiMission`：好人永远成功；邪恶在第一次任务略收敛，之后高概率失败，也可以成功伪装。
- `aiAssassinate`：只使用公开投票历史给好人打分（在含邪恶队伍上反对、在干净队伍上赞成最像梅林），从不读取角色。

自对弈覆盖 40 个种子，校验任务人数、投票记录、失败票不超过队伍邪恶人数、任务轨道与比分一致、赢家合法、同种子可复现。

## 4. 界面与美术

- 五人圆桌：中间是毛毡圆桌与阶段信息，五个座位按五边形环绕；座位在提名/暗杀阶段变成可选按钮。
- 任务轨道：5 个石质任务卡槽，显示人数、状态、失败票；下方是连续否决 5 点计数。
- 身份卡：羊皮纸质感，显示自己的角色、阵营、能力与知识 chips；不会出现其他玩家真实角色。
- 行动区：提名确认、赞成/反对、任务成功/破坏、暗杀目标；全部按钮 ≥44px。
- 深色/浅色主题、身份翻转、任务卡翻面、轮次呼吸、暗杀匕首、结算浮层；`prefers-reduced-motion` 下全部关闭。
- 音效复用 `games/shared/sfx.js`，页面不出现 `AudioContext` 或 `createOscillator`。
- 美术：6 个 img-gen 单物件材质（圆桌毛毡、羊皮纸、任务石板、剑、盾、王冠），封面 1200×1200、OG 1200×630、详情 1200×800 ×2，全部由 `art-render.html` + `render-art.mjs` 代码合成，无外部请求。
- 390×844 / 320×568 / 横屏验证：无横向滚动、可见字号 ≥12px、交互目标 ≥44px。

## 5. 联机架构

- 房间/邀请/密码/重连/超时托管/排行榜全部复用 `games/shared/online-room-server.mjs`；本游戏只提供 `online-server.mjs` 适配器。
- 服务端权威：提名、投票、任务卡、暗杀都由服务端 engine 判定；客户端只渲染 `adapter.view(match, seat)`。
- 隐藏身份：每个座位收到不同投影；`publicView` 不包含其他玩家角色字段，结束后才通过 `result.roles` 与 `state.reveal` 翻牌。
- 座位：官方 5 人，两名真人 + 三名 AI（或一名真人 + 四名 AI）恰好坐满五席。
- 超时：15 秒无请求自动托管；`reconnect` 清除托管并恢复人类座位。
- `online.html` 是大厅 + 圆桌：创建、加入、邀请复制、开始、提名选人、投票、任务、暗杀、结算、重赛、排行榜。
- 端到端证据：`test-online.js`（62 断言，纳入 run-all）与 `e2e.mjs` 的浏览器联机段。
