# 多米诺王国 · Kingdomino — Premium 设计说明

## 1. 游戏与目标

48 张真实多米诺瓦片，两人局抽 24 张；地形接续、面积 × 皇冠，5×5 王国。

- 设计者：Bruno Cathala（2016）
- 人数：2（实现）/ 2–4（官方）
- 时长：15–20 分钟；建议年龄 8+
- 荣誉：Spiel des Jahres 2017 红标奖（Kennerspiel 提名/家庭游戏奖）
- 本实现：两人人机对战 + 双人联机房间（空位 AI 补位）。

## 2. 规则内核

- **数据**：48 张瓦片、96 格、39 顶皇冠；每张瓦片两半各有地形与皇冠数，编号与公开牌表一致。
- **轮次**：两人局随机抽 24 张，6 轮、每轮 4 张待选；按队列顺序每人选 2 张。本轮选牌位置决定下一轮先手。
- **放置**：新瓦片必须与已有领地上下左右相邻，至少一格地形相同；城堡四边视为任意地形；不得超出 5×5。
- **弃置**：若当前瓦片在自己王国没有任何合法位置，必须弃置；不能因为不想放而主动弃置。
- **计分**：同地形连通成领地，得分 = 领地格数 × 该领地皇冠总数；总分相同比最大领地，再相同共享胜利。

规则引擎位于 `engine.js`（UMD，无 DOM、无 Math.random，随机性只来自 `createGame(seed)` 的 mulberry32）；数据表位于 `data.js`；所有动作先经合法性检查，`applyMove` 返回全新 state。AI 只从 `getLegalMoves` 中选择，并使用确定性 tie-break，保证同种子可复现。

## 3. 视觉系统

- **单物件**：六种地形（麦田、森林、湖泊、草原、沼泽、矿山）各一张俯拍纹理；空白卡纸瓦片与橡木王棋单独生成。
- **材质**：瓦片为卡纸、王棋为木制；页面给地形格叠加真实纹理，保留原 SVG 图标与皇冠。
- **合成**：封面/OG/详情由代码摆出真实 5×5 王国与待选队列，字符与数字由字体渲染。
- **字体**：标题 Songti SC Bold 700；可读字号 ≥12px，触控 ≥44px。

页面采用「深色桌面 + 暖金线条 + 宋体标题」的统一语汇；卡面、瓦片、筹码与桌面纹理来自 img-gen 单物件生成，再由 CSS 混合模式与代码排版合成。封面、OG 与详情图分别在 `assets/cover.webp`、`assets/og.webp`、`assets/detail-1.webp`、`assets/detail-2.webp`，PNG 母版同目录保留。

## 4. 手机与联机

- 390×844 与 320×568 两档真实浏览器冒烟；无横向滚动、可读字号 ≥12px、主触控目标 ≥44px、输入框 16px 防止 iOS 缩放。
- `online.html` + `online-server.mjs` 复用 `../app/rooms.js` 的房间/邀请/密码/TTL；服务端用同一 `engine.js` 权威判定。
- 空座 AI、断线重连、超时托管、结果榜、重赛；`test-online.js` 用两个独立 HTTP 客户端验证同局与结算一致。

## 5. 复用与边界

- `games/shared/shuffle.js`：引擎洗牌；`games/shared/sfx.js`：页面音效；`games/shared/rewards.js`：单机终局 XP/等级/连胜；不复制共享实现。
- `games/shared/leaderboard.js` 指向外部 worker，为保持零外部请求不接入页面；联机榜单由 `online-server.mjs` 本地实现。
- 规则页 `rules.html` 列出 B 站来源与公开文字规则核对；`realism.json` 记录件数/尺寸/比例/颜色/材质/规则六类校验。
- 不改共享入口；`meta.json` 由最终合并统一纳入目录。

## 6. 性能预算

FCP ≤ 2500ms、loadEventEnd ≤ 4000ms、DOM ≤ 2500 节点、新局渲染 ≤ 200ms、材质 ≤ 1.5MB、外部请求 0。实测见 `perf.json`。
