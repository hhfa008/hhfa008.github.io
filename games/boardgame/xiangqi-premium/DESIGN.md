# 中国象棋 · 楚河汉界 — DESIGN

## 目标

把 `games/xiangqi/` 的简版升级为可长期运营的 premium 版本：完整规则、可信材质、手机两档可用、三档 AI、同屏双人与 2 人联机。规则以中国象棋通行竞赛规则为准，视觉按 `games/ART-GUIDE.md`：**AI 只提供单物件材质，棋盘、棋子字符、局面全部由代码绘制**。

## 信息架构

- `index.html` — 棋盘页：SVG 棋盘、木质棋子、着法记录、吃子区、模式与难度、结果层、联机模式。
- `online.html` — 联机大厅：创建 / 邀请 / 加入 / 房间座位 / 开始 / 重连 / 结果榜。
- `rules.html` — 规则与入门：棋子走法表、将军与判和、中文记谱、FAQ（Article + FAQPage JSON-LD）。
- `engine.js` — 纯规则引擎：走子生成、将军检测、将帅照面、记谱、60 回合与三次重复判和、α-β 搜索。
- `online-adapter.mjs` + `online-server.mjs` — 绑定共享房间服务器的象棋适配器。
- `test.js` / `test-online.js` / `e2e.mjs` — 单测、双客户端联机、真实浏览器 E2E。

## 视觉

| 元素 | 做法 |
|---|---|
| 桌面 | img-gen 深胡桃木台面材质，`table-walnut.webp` |
| 棋盘 | img-gen 浅枫木材质 + 代码绘制九路十行、九宫斜线、楚河汉界、炮兵位标记 |
| 棋子 | img-gen 空白黄杨木圆片材质；红/黑字、内圈、投影、纹理全部由 SVG 代码合成 |
| 字体 | 标题与棋子使用 `Songti SC` **Bold 700**（ART-GUIDE：900 缺字） |
| 动效 | 走子 200ms 位移、最后一步标记、被将军红圈脉冲；`prefers-reduced-motion` 关闭 |
| 配色 | 黑胡桃 `#1a100b`、象牙 `#f4e7cf`、赤金 `#d8b26a`、朱红 `#a5241b`、墨黑 `#241a12` |

尺寸：棋子 Ø30mm、厚 10mm；棋盘 9 路 × 10 行；成品封面 1200×1200、OG 1200×630、详情 1200×800。

## 交互

- 点选棋子 → 高亮合法落点（金点为空位、红虚线圆为吃子）→ 点落点走子。
- 人机：玩家执红，AI 执黑；三档搜索深度 1 / 2 / 3，时间上限 120 / 300 / 700ms。
- 同屏双人：红黑轮流，不自动走子。
- 悔棋：人机一次退回双方各一步，双人一次一步；AI 思考中禁用。
- 结果层：将死 / 困毙 / 60 回合无吃子 / 三次重复 / 认输；可查看棋盘。
- 联机：`?online=<roomId>&session=...&player=...`，1.3s 轮询，服务端权威判定。

## 规则要点

- 马腿、象眼、炮架、过河兵、九宫限制、将帅照面全部在生成合法着法时检查。
- 无合法着法即负（将死与困毙同判）。
- 120 个半回合无吃子判和；同一局面（棋盘 + 行棋方）第三次出现判和。
- 中文记谱：红方路数从右向左 9→1，黑方 1→9；横走“平”，斜行棋子记目标路，直线棋子记步数。

## 数据与联机

- 无隐藏信息，公开状态包含棋盘、行棋方、着法记录、吃子、将军与结果。
- 房间、邀请、密码、重连、超时托管、结果榜复用 `games/shared/boardgame-room-server.mjs`，房间底层复用 `games/boardgame/app/rooms.js`。
- 空位 AI 补位；约 15 秒无操作座位转 AI，重连收回。
- 不采集 PII；页面零外部请求。

## 取舍

- 不实现长将 / 长捉的裁判细则，统一用三次重复判和；规则页明确写出。
- 不做棋谱导入导出；着法记录只保留本局。
- 联机为 2 人房；本地 AI 与同屏双人不受联机约束。
