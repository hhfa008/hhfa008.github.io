# 骷髅牌 SKULL · PREMIUM — 设计

> 版本 1.0.0 · 2026-11-10 · `games/boardgame/skull-premium/`

## 1. 目标

把 3–6 人的《骷髅牌》做成一个手机竖屏可一局到底的精品网页：真实杯垫数量、真实放置/叫价/翻牌流程、真实的失去牌与 2 分赛制；单人可对 AI，联机房间可跨设备同局。

## 2. 规则口径

- 3–6 人；每人 4 枚杯垫：3 玫瑰 + 1 骷髅。
- 放置：顺时针，每人每次放 1 枚到自己牌堆顶或停手；起始玩家在空桌时不能停手；所有人停手后由最后放牌者开叫。
- 叫价：从 1 起递增，最高不超过桌面已放置总数；停叫者退出本轮叫价；只剩最高叫价者时执行挑战。
- 翻牌：可翻任意牌堆最上面一张；只有挑战者可以继续往下翻自己的牌堆；翻到骷髅立即失败。
- 成功：得 1 分，先到 2 分获胜；所有已放置/翻开的牌回到各自主人。
- 失败：所有牌先回到手中，失败者从手中随机失去 1 枚；失去全部牌出局。
- 边界：叫价高于可翻牌数时，翻开所有可达牌后仍未达标即判失败（避免死局）。

## 3. 引擎

`engine.js` 纯函数 UMD：

- `createGame({seed, playerCount, names, isAI})`：3–6 人，每人 3 玫瑰 + 1 骷髅。
- `getLegalMoves(state)`：放置 / 停手 / 叫价 / 停叫 / 翻牌，按阶段枚举。
- `applyMove(state, move)`：深拷贝后结算；非法动作抛 Error；不修改入参。
- `chooseAIMove(state)`：放置时把骷髅埋在底层；叫价按自己已知玫瑰 + 对手概率估算；翻牌优先自己已知玫瑰。
- `getView(state, seat)`：对手牌堆与手牌构成隐藏；已翻开的牌公开；对局结束后公开。
- 失去牌的随机选择复用 `games/shared/shuffle.js` 的 seeded Fisher-Yates，整局可由 seed 复现。

## 4. 界面

- 单页 `index.html`：酒吧木桌、玩家牌堆、翻牌区、叫价区、手牌杯垫、日志、结算/比赛弹窗。
- 交互：放置阶段点杯垫两次确认；叫价阶段点数字再确认；翻牌阶段直接点高亮牌堆。
- 颜色：六位玩家各有杯垫环色（墨黑 / 铁锈 / 苔绿 / 靛蓝 / 梅紫 / 赭黄），牌堆一眼可辨。
- 移动端：320px 下 6 名玩家自动换成 3 列；所有按钮 ≥44px；文字 ≥12px；无横向滚动。
- 无障碍：aria-label、aria-live 日志、焦点环、reduced-motion。

## 9. 风险与边界

- 叫价高于可达牌数时判失败：这是为唯一合法动作集清空时的死局兜底，物理规则通常由玩家自行避免。
- AI 只用公开信息 + 自己的牌堆做概率估算，不读取对手暗牌。
- 自动进入下一轮：结算后立即发新轮，UI 用 `lastRound` 弹窗展示上一轮。
