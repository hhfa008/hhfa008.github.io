真实规则

  • 红 9、蓝 8、中立 7、刺客 1；红队先手。
  • 队长线索 = 一个词 + 数字；最多猜「数字 + 1」次。
  • 猜错/中立立即换边；踩刺客立即落败。
  • 先找齐己方全部词获胜；翻出对方最后一张词也会让对方获胜。

美术与材质

  • 词卡纸面、卡背、桌面绒布为本地 1024 PNG 母版 + 512 WebP 引用。
  • 纯白背景、单物件居中、左上主光、真实纸纤维/亚麻压纹/羊毛毡。
  • 完整局面、字符与花色/图标由代码与内联标准 SVG 渲染，不用 AI 画文字。
  • 零外部图片、字体、CDN 或追踪。

手机适配

  • 390×844、320×568 冒烟；844×390 横屏与 1024×768 平板不崩。
  • 触控热区 ≥44px；无横向滚动；100dvh；四边 safe-area。
  • iOS Safari：touchstart/pointerdown 首次解锁 WebAudio；无 hover 依赖。
  • 键盘方向键在 5×5 网格移动焦点。

联机能力

  • 房间/邀请/密码房由共享 app/rooms.js 状态机处理。
  • 4 座位：红队队长 / 红队队员 / 蓝队队长 / 蓝队队员；空位 AI。
  • 断线重连、超时 AI 托管、结果入服务器内存榜。
  • 双客户端 HTTP E2E 已纳入 run-all.js。
