games/shared/physics.js

轻量 2D 物理引擎演示

固定步长 + 子步进、圆 / AABB 碰撞、弹簧与固定点约束、休眠与确定性。下面两个场景都由同一个引擎驱动，没有使用 CSS 关键帧伪造运动。

无依赖 确定性 60Hz 固定步长 v1.0.0

① 发牌动效

牌从牌堆以不同初速度射出，落地弹跳，随后由弹簧吸进目标位。每张牌都是 AABB 刚体，旋转角只用于渲染。

② 棋子跳跃

从 A 格到 B 格的一次抛物线跳跃，落地时由物理碰撞触发渲染层的压缩变形（缩放，不改变刚体）。

—
// 两行就能跑起来
const world = Physics.createWorld({ gravity: { x: 0, y: 900 } })
const card  = world.addBody({ shape: 'aabb', w: 80, h: 110, x, y, mass: 1,
                               restitution: 0.3, friction: 0.4 })
Physics.spring(card, { x: targetX, y: targetY }, { stiffness: 120, damping: 14 })
Physics.applyImpulse(card, { x: 260, y: -380 })
world.step(dt)   // 内部按 1/60 固定步长推进
