我该怎么开始

三条命令覆盖「跑测试 → 看任务 → 验一条任务」。点右侧按钮即可复制。

  1. 1
    node games/tests/run-all.js

    跑全站测试；所有任务完成后都要求这条命令 0 failed。

  2. 2
    node scripts/check-tasks.js

    校验 TASKS.json 的结构与依赖引用；具体任务见下方卡片。

  3. 3
    node scripts/check-tasks.js --task <任务id>

    只验一条任务；把 <任务id> 换成卡片上显示的 id。
